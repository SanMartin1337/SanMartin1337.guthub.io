## Как пользоваться

1. Откройте [ссылку](https://sanmartin1337.github.io/SanMartin1337.guthub.io/) в браузере телефона или компьютера.
2. Нажмите на зону загрузки и выберите один или несколько файлов `.xlsx`. На компьютере файлы можно перетащить.
3. Дождитесь обработки и нажмите **Скачать**.

Готовый файл называется **`имя_файла_sortirovka.xlsx`**:

- на Samsung и других android он окажется в «Загрузках»;
- на iPhone откроется меню сохранения, файл можно положить в «Файлы».

**Совет:** добавьте страницу на главный экран, и она будет открываться как обычное приложение. В Chrome это «Добавить на главный экран», в Safari «Поделиться → На экран Домой».

---

## Конфиденциальность

Файлы **не загружаются на сервер**. Всё считается в самом браузере, на вашем устройстве. На странице нет сторонних скриптов, статистики и внешних библиотек, нет даже обращений к другим сайтам.

---

## Что умеет

Программа сама определяет формат файла по колонкам. Файлы разных форматов можно загружать вместе, каждый формат соберётся в свой общий файл.

### Выгрузка по коробам

| Обязательные колонки |
|---|
| `Модель` · `Код упаковки SSCC` · `Размер` |

Результат: **Сводка** (коробы, пары, разбивка по размерам, итого) и **лист на каждую модель**, отсортированный по коробу и размеру. Предупреждает, если в коробе больше 8 пар или смешаны разные модели.

### График поставок

| Обязательные колонки |
|---|
| `Модель` · `Кол-во коробов` · `Кол-во пар` |

Результат: **Сводка** (коробы и пары по моделям и по каждой поставке), лист **Поставки** со сверкой итогов и **лист на каждую модель**. Предупреждает о расхождении дат в названии файла и внутри него, о несходящихся итогах и о нескольких артикулах или ценах у одной модели.

Город поставки берётся из названия файла до первого символа `_`.

## Публикация на GitHub Pages

Всё приложение состоит из одного файла **`index.html`**.

1. Положите `index.html` в корень репозитория.
2. Откройте **Settings → Pages**.
3. В **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт появится по ссылке, которая показана в верхней части страницы Pages.

**Чтобы обновить приложение,** загрузите новый `index.html` через **Add file → Upload files**. Он заменит старый, и через минуту сайт обновится. Если браузер показывает старую версию из кэша, обновите страницу ещё раз.

## Как это устроено

- Один файл на чистом HTML, CSS и JavaScript, без сборки и зависимостей.
- Чтение `.xlsx`: собственный разбор zip (распаковка встроенным `DecompressionStream`) и XML.
- Запись `.xlsx`: собственный генератор файла, который формирует Excel-совместимый архив.
- Спецсимволы в кодах маркировки сохраняются без искажений.
- Оформление на системных шрифтах, без внешних шрифтов и картинок.

## Требования и ограничения

- Современный браузер: Chrome и Edge, Safari 16.4+, Firefox 113+.
- Поддерживается только `.xlsx` (не `.xls`).
- Чтобы открыть страницу, нужен интернет. Автономного режима нет.
- Файлы одного формата должны иметь одинаковые колонки.
- Даты в листах моделей для графика поставок записываются текстом `ДД.ММ.ГГГГ`.
